# 🚀 Top 1% Android, KMP & Mobile AI Roadmap Tracker

A minimalistic, glassmorphic, responsive checklist and mastery tracker for senior Android & KMP & Mobile AI engineers.

Built with **Bootstrap 5**, **Bootstrap Icons**, **Glassmorphism & Neumorphic Design**, and **Persistent LocalStorage**.

---

## ✨ Features

- **100+ Elite Skills**: Covers all 7 domains:
  1. *Languages & Compilers* (FIR/IR, KSP2, Swift 6, C++, 16KB pages, etc.)
  2. *KMP Stack* (Compose Multiplatform, Decompose, Room KMP, Maestro, etc.)
  3. *Mobile AI & Edge* (LiteRT, Gemini Nano, ExecuTorch, QNN, on-device RAG, etc.)
  4. *Backend & Infra* (Spring Boot, Ktor, Postgres, Docker, K8s, Passkeys, etc.)
  5. *APIs* (OpenAPI, gRPC/Protobuf, GraphQL federation, streaming, LLM gateway)
  6. *Mobile System Design* (Offline sync/CRDTs, caching, feature flags, threat modeling)
  7. *Career Leverage* (OSS, talks, platform metrics, Tier-1 interview prep)
- **Persistent State**: Keeps track of every skill you check off using browser `localStorage`. Your progress stays saved even after closing or refreshing the tab.
- **Glassmorphic UI**: High-end cyber-dark theme with blurred glass cards, subtle neon accents, and smooth micro-interactions.
- **Live Search & Filter**: Instant search by keywords and filter by *All*, *Pending*, or *Completed*.
- **Metrics & Category Bars**: Real-time completion percentages globally and per category.
- **Export & Import**: Backup your progress to a `.json` file or restore it on any device.

## 🌐 How to Host on GitHub Pages (Free, 1 Minute)

Follow these steps to host your tracker live on GitHub:

### Option A: Using the Terminal / Git

1. **Initialize git and commit the files** (already prepared):
   ```bash
   git init
   git add .
   git commit -m "feat: Top 1% Android Dev Tracker"
   git branch -M main
   ```

2. **Create a new repository on GitHub**:
   - Go to [github.com/new](https://github.com/new)
   - Repository name: `top-1-android-dev` (or any name you prefer)
   - Set it to **Public**
   - Do **not** initialize with README or .gitignore (keep it empty)
   - Click **Create repository**

3. **Link and push to GitHub**:
   ```bash
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
   git push -u origin main
   ```

4. **Turn on GitHub Pages**:
   - On your GitHub repo page, click **Settings** (top tab)
   - In the left sidebar, click **Pages**
   - Under **Build and deployment > Source**, select **Deploy from a branch**
   - Under **Branch**, choose `main` and folder `/ (root)`, then click **Save**
   - Wait 30-60 seconds, and your site will be live at:
     ```
     https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/
     ```

---

### Option B: Drag and Drop via GitHub Web UI

1. Create a new repository on [github.com/new](https://github.com/new).
2. Click **Upload an existing file**.
3. Drag and drop `index.html` and `README.md` into GitHub.
4. Click **Commit changes**.
5. Go to **Settings > Pages**, choose `main` branch, and click **Save**. Done!
